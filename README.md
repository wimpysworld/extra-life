<p align="center"><b>Give Extra Life to Classic Games and Hardware 🕹</b></p>

[Extra Life](https://extralife.wimpys.world) is a clean, uncluttered operating system for a game console that gets you to your classic games fast. Turn a spare personal computer (PC), single-board computer, or handheld into a dedicated game console with a simple menu that you control with a gamepad.

## Download and Device Finder

Pick the image for your device, write the image to a Secure Digital (SD) card or Universal Serial Bus (USB) drive, and start your games:

- [Find Your Device and Download on the Extra Life Website](https://extralife.wimpys.world/devices.html)
- [Browse Latest Downloads on GitHub Releases](https://github.com/wimpysworld/extra-life/releases)

## Why Extra Life

- **Built like a console**: Turn on your device and pick a game with your controller. Wi-Fi, Bluetooth controllers, audio, and display settings work straight from the controller menu.
- **Ready to play out of the box**: Over 40 classic consoles, handhelds, and arcade systems are pre-configured. You do not need to download emulator cores or configure complex menus.
- **Install once, updates itself**: Download over-the-air updates straight from the settings menu. Each update keeps an automatic backup of the previous version for safe recovery.
- **Copy games your way**: Copy game files onto the SD card or USB drive, or turn on file sharing over Wi-Fi in the settings menu. On Wi-Fi, `Extra Life` appears as a shared network folder in Windows File Explorer (`\\extra-life\Retro`), macOS Finder (`smb://extra-life.local/Retro`), and Linux file managers. You can also enable Secure Shell (SSH) if you prefer command-line transfers.
