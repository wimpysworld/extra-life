NixOS retro game appliance

Extra Life

Give Extra Life to Classic Games and Hardware 🕹️. Extra Life is a console-grade retro game appliance that runs Ludo on Wayland for x86_64 personal computers (PCs), Raspberry Pi boards, and ARM handhelds.

The appliance has zero text consoles, zero RetroArch menus, and automatic over-the-air (OTA) updates.

Features

Built like a console

Extra Life replaces a general-purpose Linux desktop with a dedicated Wayland kiosk that boots straight into your game library.

01 Pure Console Appliance
The system boots straight into Ludo on the Cage Wayland compositor with controller navigation, Wi-Fi, Bluetooth, and audio controls.
02 33 Curated Emulation Cores
You can play classic arcade, 8-bit, 16-bit, 32-bit, and 64-bit systems out of the box without manual core downloads.
03 Power-Safe SquashFS & OTA Updates
The system runs from a read-only compressed image that protects Secure Digital (SD) cards and updates from the Ludo menu.
04 PC, Raspberry Pi, and Handhelds
One unified platform supports x86_64 PCs, Raspberry Pi boards and cases, and ARM handhelds.

Get started

Try Extra Life

Download a disk image from GitHub Releases, or run just boot-disk to boot the local QEMU virtual machine (VM).

Enable Samba or Secure Shell (SSH) in Ludo, then copy read-only memory (ROM) files to /storage/Retro/roms.

Download an image Read the documentation

Boot the local VM or copy ROMs

# Build and boot the writable 64 GB UEFI disk image in QEMU
just boot-disk

# Copy ROMs over SSH (port 2222 in vm-retro, or port 22 on hardware)
rsync -avP ./roms/ ludo@extra-life.local:/storage/Retro/roms/

You can also open the Retro network share over Samba to copy ROMs, Basic Input/Output System (BIOS) files, saves, and screenshots.

Questions

Frequently asked questions

Which systems and hardware does Extra Life support?

Extra Life ships 33 curated Libretro cores for Arcade, Atari, Bandai, ColecoVision, MSX, Vectrex, Odyssey2, NEC, Nintendo, Sega, SNK, and Sony systems. Hardware support covers x86_64 PCs and handhelds, Raspberry Pi 4, 400, 5, and Zero 2 W, and ARM handhelds.

How do I copy ROMs and BIOS files to /storage/Retro?

Enable Samba or SSH from the Ludo settings menu. Over Samba, copy ROM files into roms/<Playlist Name>/ and BIOS files into system/. Over SSH, copy files directly to /storage/Retro/roms and /storage/Retro/system as user ludo.

How do OTA updates work?

Extra Life boots from a read-only compressed /boot/SYSTEM SquashFS image and runs zero Nix binaries at runtime. Ludo downloads a verified extra-life-<variant>-<version>.tar archive into /storage/.update/ and reboots. During early boot (initrd), the appliance saves the previous system as .prev for rollback and activates the new image.

How can I test Extra Life in vm-retro?

Clone the repository and run just boot-disk, just boot-iso, or nix run .#vm-retro on Linux or Apple Silicon macOS. The runner starts QEMU with hardware acceleration, audio passthrough, persistent storage in .vm/, and SSH on host port 2222.
